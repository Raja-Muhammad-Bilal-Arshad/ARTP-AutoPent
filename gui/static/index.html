What this console is

      
A local browser interface over the poc/ package —
        the paper-faithful, simulation-only proof of concept. The server is a
        thin shell: planning, verification, HITL, execution and metrics are
        all performed by the same code the CLI uses
        (poc.pipeline.run_pipeline, poc.exp), so
        GUI results are the PoC's results.

      
Everything is simulation-only: no exploit payloads, no
        live targets, seeded/deterministic PRNG, sandbox-scoped.

      
Requirements

      
    
        
  • Python ≥ 3.10 (validated on 3.13) — no extra packages needed to
            start: the server is stdlib-only.
    • 
        
  • matplotlib — required only for the Experiments
            tab (it regenerates the figures). One run needs no dependencies
            beyond Python.
    • 
        
  • z3-solver — optional; upgrades the verifier
            engine label from python-bfs-smt-style to
            z3-smt.
    • 
      

      
Launch

      
./run_gui.sh                    # opens http://127.0.0.1:8787
python3 -m gui.server --port 8787 --host 127.0.0.1 --no-browser

      
The server binds 127.0.0.1 only — it is never
        reachable from the network.

Safety & scope

      
The GUI inherits the PoC's guarantees: every step passes the
        6-verb schema, blocklist, scope checks, SMT-style feasibility and the
        non-bypassable human gate before it is "executed" against a
        simulated sandbox. Nothing here touches, scans or exploits any byte
        on any network.

      
Where the code lives
